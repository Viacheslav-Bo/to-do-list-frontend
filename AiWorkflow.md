# AI Workflow

## Tools

- **ChatGPT / Claude** — used for architecture discussions, debugging, code review, and implementation suggestions.

## Workflow

Rather than generating the entire application automatically, AI was used as a development assistant while all features were implemented, integrated, tested, and refined throughout development.

## How AI Helped

AI was primarily used for:

- Discussing application architecture and project structure.
- Explaining framework-specific behavior (Next.js, React Query, Zustand, Zod, MongoDB).
- Debugging issues that were difficult to identify.
- Reviewing code and suggesting improvements.
- Generating an initial Playwright E2E test suite.

## Verification

AI-generated suggestions were not accepted blindly. Every change was reviewed, integrated manually when necessary, tested locally, and validated against the project requirements before becoming part of the final application.
